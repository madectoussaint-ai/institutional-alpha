Architecture
GitHub Actions lance update_data.py chaque heure. Le script récupère les derniers cours disponibles et 30 jours d'historique, recalcule le momentum, puis met à jour data.json.
Limites
Ce système est gratuit et utile pour une simulation, mais ce n'est pas un flux professionnel tick-by-tick. Yahoo Finance via yfinance peut être retardé ou occasionnellement indisponible. Les données institutionnelles restent soumises à leur cadence officielle.
